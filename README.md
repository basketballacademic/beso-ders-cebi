BESÖ Ders Cebi – kurulum
1) Bu klasörü herhangi bir HTTPS statik sunucuya yükleyin (GitHub Pages, Netlify Drop, Cloudflare Pages vb.).
2) Telefonda adresi bir kez açın. Android Chrome: menü > Uygulamayı yükle / Ana ekrana ekle. iPhone Safari: Paylaş > Ana Ekrana Ekle.
3) İlk açılıştan sonra uygulama tamamen çevrimdışı çalışır.
İnternetsiz alternatif: index.html dosyasını telefona kopyalayıp tarayıcıda açabilirsiniz; içerik dosyanın içindedir.
Podcastler cihazın Türkçe metin okuma sesiyle çalar (Ayarlar > Metin okuma çıktısı > Türkçe ses paketi).
